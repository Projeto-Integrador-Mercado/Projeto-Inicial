# Mercadinho Silva Camargo

Projeto Integrador de ADS — controle de entrada e saída de produtos.

## Organização

- `mercadinho-atualizado/`: versão atual indicada pela equipe.
- `Projeto Final/`: entrega anterior de Desenvolvimento Web.
- `Diagrama de classes - PI/`: diagrama de classes.
- `Telas - Figma/` e `Telas - GoogleStitch/`: referências de interface.
- [Quadro do projeto](https://github.com/orgs/Projeto-Integrador-Mercado/projects/2/views/1).
- [Guia de contribuição](CONTRIBUTING.md): commits, branches, pull requests e definição de pronto.

## Fluxo de trabalho

`branch da tarefa → pull request para dev → pull request de dev para main`

`dev` reúne o trabalho em integração; `main` recebe entregas verificadas. Cada tarefa deve ter uma issue, evidências e os links dos PRs no quadro. Marcar **Done / Feito** somente após a integração na `main` e a verificação dos critérios.

## Situação desta etapa

A etapa 1 organiza a colaboração no GitHub. O código do sistema e os diagramas não são alterados por esta etapa. A revisão das relações de fornecedor, dos ajustes de estoque e das incoerências entre código e diagrama será realizada separadamente. A existência de um arquivo não comprova que a funcionalidade foi validada.
