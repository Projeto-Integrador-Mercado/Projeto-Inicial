# Controle de Mercado

Projeto Integrador do 2º semestre de Análise e Desenvolvimento de Sistemas — FATEC Sorocaba.

## Proposta

Desenvolver um sistema simples de controle de estoque para o **Mercadinho Silva Camargo**, com acesso por login e registro de entradas e saídas de produtos.

Nesta etapa, o projeto está em planejamento e o backlog contém somente duas tarefas iniciais:

1. **[US-001 — Tela de login](https://github.com/Projeto-Integrador-Mercado/Projeto-Inicial/issues/1):** formulário, validação dos campos e mensagens de acesso.
2. **[US-002 — Backend de entrada e saída de produtos](https://github.com/Projeto-Integrador-Mercado/Projeto-Inicial/issues/2):** registro das movimentações, atualização do saldo e validação para impedir estoque negativo.
