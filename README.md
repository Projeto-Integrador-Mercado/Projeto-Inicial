# Mercadinho Silva Camargo

Projeto Integrador de ADS — controle de entrada e saída de produtos.

## Organização

- `mercadinho-atualizado/`: versão atual do sistema.
- `docs/`: discovery, requisitos e orientações do quadro.
- `docs/diagramas/`: diagrama de classes.
- `docs/entregas/`: documentos e arquivos das entregas acadêmicas.
- `prototipos/figma/` e `prototipos/stitch/`: referências de interface.
- `arquivo/projeto-final/`: entrega anterior de Desenvolvimento Web.
- [Quadro do projeto](https://github.com/orgs/Projeto-Integrador-Mercado/projects/2/views/1).
- [Guia de contribuição](CONTRIBUTING.md).

## Fluxo de trabalho

`branch da tarefa → pull request para dev → pull request de dev para main`

`dev` reúne o trabalho em integração; `main` recebe entregas verificadas. Cada tarefa deve ter uma issue, evidências e os links dos PRs no quadro. Marcar **Done / Feito** somente após a integração e a verificação dos critérios.
